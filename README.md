<h3> C BALL RUN</h3> <h4>( c what i did there? )</h4>

<h5>Game description</h5>
Its basically a steel ball run (jjba part 7) based text adventure style game , in which you are dealt 1 card every turn, that card can be 3 things - a maneuver you can use to get ahead of your opponents, a consumable you can use to survive, or a combat move you can use to sabotage and attack your opponents.
But these cards also have energy costs. Energy can only be gained by advancing in the race (passively resting for a turn) , allowing opponents to move forward.  Additionally , a maximum of 10 cards can be held at a time, any number of cards can be played at once (before advancing) as long as you have the energy to do so.

<h5>How to run</h5>
To run locally, just download the script, and you can either run independently on any c compiler of your choice or use an c compiler extension on a code editor of your choice.

<h5>My experience</h5>
This was a very small project, and as a result I encountered virtually zero difficulties, it was my first time working with C so that was a bit troublesome wrapping my head around the semi colon at the start but I got the hang of it pretty quick.
The hardest part was surprisingly the database, it took a bit of effort to come up with like 30-ish cards that were somewhat relevant and i feel like the consumables section was a bit lazy and repetitive and had a lot more potential.
